# Google Data Fetcher

This project uses [SerpApi](https://serpapi.com/) to fetch data from Google Search and save the results to a CSV file.
The script automatically excludes duplicate domains from the results.


## Setup

Before you start, ensure you have the following installed:

- [Node.js](https://nodejs.org/) (preferably the latest LTS version),
- An API key from [SerpApi](https://serpapi.com/). You must create a local .env file with your API_KEY

## Start
- `npm install`
- `npm run start`
